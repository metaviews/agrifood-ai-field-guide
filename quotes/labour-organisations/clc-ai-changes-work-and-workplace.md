## Quote / Position

> "AI is already having far-reaching effects on employment and job security, job design, work organization and the task composition of work, and workplace monitoring, data extraction and management."

## Context

This is the CLC's clearest compact statement that AI changes the organisation of work, not only the number of jobs. It is useful for introducing the displacement / monitoring / task-composition distinction in Archetype 08.
