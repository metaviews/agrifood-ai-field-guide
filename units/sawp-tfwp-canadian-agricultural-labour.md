The Seasonal Agricultural Worker Program (SAWP) and the Temporary Foreign Worker Program (TFWP) are the substantive Canadian federal migration programmes for agricultural workers. Per the global cycle's `scans/2026-07-ai-and-labour.md` §7 (negative-finding-tolerance track): **SAWP + AI deployment data is substantively corpus-thin across the corpus.** This unit closes G-375 substantively for Canada by surfacing the SAWP + TFWP + Canadian agricultural labour context + AI deployment interaction.

### SAWP — Seasonal Agricultural Worker Program

**What it is.** The SAWP is the bilateral Canadian federal migration programme with Caribbean countries (primarily Jamaica) + Mexico for seasonal agricultural workers. Established 1966 (Caribbean bilateral); expanded to Mexico bilateral 1974.

**Scale:**
- ~60,000+ SAWP workers annually (per `units/ufcw-nfu-clc-canada-labour-producers.md` and `scouts/2026-07-canada-ai-and-labour-scout.md`).
- Workers concentrated in Ontario + Québec + BC fruit + vegetable + tobacco farms.
- Wage determination + employer-paid transportation + housing + Adverse Effect Wage Rate (AEWR).

**SAWP worker characteristics:**
- Predominantly Caribbean (Jamaica) + Mexican origin.
- Seasonal (typically 6-8 month contracts).
- Workers are *not* UFCW-organised in the conventional sense; the UFCW representation is *structural* (food processing workers) rather than *direct* (SAWP + TFWP farm workers).
- Language: English (Jamaica); Spanish (Mexico); indigenous-language speakers (Mixe, Zapotec, etc.) in Mexican source regions.

**AI deployment interaction:**
- Canadian orchard AI (CropVue + OKSIR codling moth smart trap BC) names *labour-cost reduction* as deployment driver; the SAWP cost structure (wage determination + housing + transportation) is the labour-cost structure that automation responds to.
- The structural question: does Canadian orchard AI *complement* SAWP (solves solvable tasks like trap-checking) or *substitute* SAWP (replaces SAWP workers for tasks automation can do)?
- The H-2A-equivalent for Canada is SAWP + TFWP, not yet surfaced as primary source in the corpus.

### TFWP — Temporary Foreign Worker Program

**What it is.** The TFWP is the broader Canadian federal migration programme for low-skilled workers including agricultural workers. The TFWP includes SAWP-eligible + non-eligible source countries.

**Scale:**
- ~80,000+ agricultural workers annually (estimated; broader programme scope).
- Concentrated in Ontario + Québec + BC + prairie provinces.
- Wage determination + LMIA (Labour Market Impact Assessment) requirement + employer-paid transportation + housing.

**AI deployment interaction:**
- Broader programme scope = broader AI deployment interaction context.
- TFWP agricultural workers are the labour-side context for AI deployment in Canadian fruit + vegetable + tobacco + nursery + greenhouse operations.

### Geographic concentration

Per `scouts/2026-07-canada-ai-and-labour-scout.md`:
- **Ontario** — fruit (apples, tender fruit, berries) + vegetable (corn, soybeans, canola) + tobacco + greenhouse (Haven Greens Leamington ON + Sollum).
- **Québec** — maple syrup + berries + apples + greenhouse + dairy.
- **BC** — fruit (apples, cherries, blueberries, grapes) + vegetable + nursery + greenhouse.
- **Prairie provinces** — grain + oilseed + pulse crops (less SAWP-concentrated; H-2A-equivalent is the Temporary Foreign Worker Program broader scope).
- **Atlantic** — less SAWP-concentrated; some TFWP agricultural workers.

The Canadian NA processing + Canadian orchard AI + Canadian beekeeping AI + Canadian dairy AI value chains are the structural SAWP-eligible sectors where AI deployment interacts with SAWP + TFWP worker presence.

### The structural inversion: SAWP cost structure + AI deployment as labour-substitution

The SAWP cost structure (wage determination + AEWR + employer-paid transportation + housing) is the labour-cost structure that automation responds to. The structural reading:

- **If AI deployment *complements* SAWP** (solves solvable tasks like trap-checking, precision spraying, yield estimation) → SAWP workers remain; labour-displacement is partial.
- **If AI deployment *substitutes* SAWP** (replaces SAWP workers for tasks automation can do) → SAWP workforce is reduced; labour-displacement is direct.
- **The structural inversion is the same as the global cycle's harvest-vs-weeding split** (Sullivan ethnography): the labour-displacement question is *answered differently* depending on which task + which technology + which sector.

For Canada specifically, the structural question is *whether orchard AI + dairy AI + greenhouse AI + processing AI deployment interacts with SAWP + TFWP worker presence as complement or substitute*. The corpus does not have the answer; this unit surfaces the question.
